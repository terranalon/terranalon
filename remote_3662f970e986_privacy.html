Privacy Policy

Last updated: October 30, 2026

Hermes is a personal assistant application used exclusively by its owner, Alon Samocha. It is not available to the public.

What data is accessed

With the owner's explicit permission (Google OAuth), Hermes accesses the owner's own Google Calendar, Gmail, Google Drive, Docs, Sheets and Contacts data, only to carry out tasks the owner requests (for example creating calendar events or finding a booking confirmation email).

How data is used and stored

  • Data is used only to perform the owner's requests.
  • OAuth tokens and any working data are stored only on the owner's own computer.
  • No data is sold, shared with third parties, or used for advertising.
  • Google user data is handled in line with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
